Optimistic Updates Test Scenarios

Instructions

Test the optimistic update behavior by:

  1. Opening the main app in another tab
  2. Using the buttons below to simulate various scenarios
  3. Watching how the UI responds immediately and handles errors

Scenario 1: Normal Operation

Test creating and deleting entities with the server running normally.

✓ Entities should appear immediately with shimmer effect

✓ Success notification after server confirms

Scenario 2: Server Delay Simulation

Add artificial delay to see optimistic updates in action.

✓ Entity appears immediately while waiting for server

✓ Shimmer animation during wait

Scenario 3: Server Error Simulation

Force server errors to test rollback behavior.

✓ Entity appears then disappears on error

✓ Error notification shows

Scenario 4: Network Offline

Test behavior when completely offline.

✓ Immediate rollback when offline

✓ Clear error message
