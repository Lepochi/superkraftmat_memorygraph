## 🔧 Quick Start

1. **Enable Slash Commands**: 
   ```bash
   # Commands in .claude/commands/ are automatically available
   # Type / in Claude Code to see them
   ```

2. **Run Initial Setup**:
   ```bash
   cd ~/superkraft_memory/.claude/scripts
   chmod +x *.sh
   ./update_prompts.sh --init
   ```

3. **Load Project Context**:
   ```bash
   # Claude Code should read these first:
   claude "Read @docs/context/PROJECT_CONTEXT.md to understand the system"
   claude "Read @docs/context/CODING_STANDARDS.md for code style"
   claude "Read @docs/context/CURRENT_STATE.md for current status"
   ```

4. **Use Your First Command**:
   - Type `/analyze` in Claude Code
   - Watch it analyze your current context
