# Superkraftmat Memory System

A knowledge graph memory system enabling persistent AI memory across conversations, designed for team collaboration and enterprise use.

## 🚀 Quick Start

```bash
# Clone the repository
git clone <your-repo-url>
cd superkraft_memory

# Set up the development environment
npm install

# Start the development server
npm run dev
```

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js with Express
- **Memory**: JSON-based knowledge graph
- **MCP Integration**: Model Context Protocol
- **Development**: Docker, Git, npm

## 📋 Features

- ✅ Knowledge graph memory system
